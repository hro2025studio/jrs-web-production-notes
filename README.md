# NPO法人JRS Webサイト制作（2026）
NPO法人JRSの公式Webサイト制作を担当した際の技術メモと作業ログです。  
前任者が離任し、サイト制作が止まっていたため、急遽引き受けた案件となります。

最近は MAUI アプリ開発が中心で、Web制作は約10年ぶりでした。  
そのため、当初は色々と戸惑う部分もありましたが、作業を進めながら徐々に感覚を取り戻しました。

## ■ CSS構造の見直し
当初はページ数が少ないと判断し、1つの外部CSSにまとめていました。  
しかし、オーナーからの情報提供が進むにつれてページ数が増える見込みとなったため、  
以下のようにCSS構造を再設計しました。

- **common.css**（サイト全体の共通スタイル）  
- **page-xxx.css**（ページ固有のスタイル）

前任者は CMS のみで作業しており、CSS調整は行っていませんでした。  
そのため CMS由来のCSSが強く効いており、新規CSSと競合して調整に苦労しました。  
Webが安定するまでは一部CMSのCSSを使用しますが、最終的には脱CMS構造を目指しています。

## ■ 技術理解（製品・工法）
今回の制作を通じて、以下の技術内容について理解が深まりました。

### ● JRSブロッケージ工法  
ロックウール端材（落綿）を現場で再利用する循環型の施工技術。  
専用受金物・変位追従・遮煙安定など、工法として成立させるための要素が多く、  
従来の板状ロックウールとは異なる特徴を持つ。  
産廃削減やCO₂削減にも寄与する。

### ● ゼロ・フェノール技術を活用したリサイクル農材  
ロックウール廃材を粉砕 → 高温焼去 → 再成型することで、  
フェノール樹脂を含まない安全な農材として再生する技術。  
農業用途での安全性向上と廃材の再資源化に貢献する。
